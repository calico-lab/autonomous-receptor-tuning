# Autonomous Receptor Tuning via Integral Feedback for Adaptive Molecular Communication Receivers

Code and data for the article "Autonomous Receptor Tuning via Integral Feedback for Adaptive Molecular Communication
Receivers" by Yağız Celhan and Murat Kuscu, CALICO Lab, Department of Electrical and Electronics Engineering, Koç
University.

Every number and figure of the article that is obtained from the model or the simulations is generated by the scripts
in `code` from the stored results in `results`. All simulations use fixed seeds, so that rerunning them regenerates the
stored results.

## Contents

- `code`: the Python code.
  - `model.py` implements the analytical model of the closed loop: the parameters of Table I, the receptor maps, the
    actuation laws, the steady state, the receptor gain, the linear-noise variances including the self-noise, the
    stability boundary, the Gaussian approximation of the bit error probability (BEP), the loop-speed design rule, and
    the design-point optimizer.
  - `engine.py` simulates the closed loop with random symbol streams by tau-leaping and by the exact stochastic
    simulation algorithm (SSA), and `detection.py` evaluates the exact binomial error probability of the
    fixed-threshold detector, the best non-adaptive and genie-aided receivers, and the bootstrap confidence intervals.
  - `run_*.py` run the experiments of the article, and `check_isi_step.py` and `check_modification_bep.py` check the
    integration step of the CIR-based model and the static-channel BEP of the explicit-modification model.
  - `make_numbers.py` writes every number of the article as a LaTeX macro, and `make_figures.py`,
    `make_fig4_cir_sweep.py`, and `make_fig1_schematic.py` draw the figures.

  The docstring of each script states its model, its settings, and its outputs.
- `results`: the stored results of all experiments (JSON, CSV, and NPZ files).

## Requirements

Python 3.9 with the packages in `requirements.txt` (NumPy 2.0.2, SciPy 1.13.1, and Matplotlib 3.9.4). Fig. 1 is
compiled with `pdflatex` and requires TikZ and the newtx fonts.

## Reproducing the numbers and figures

From the repository folder:

```
pip install -r requirements.txt
make
```

`make` runs the following scripts, which read the stored results in `results` and write the LaTeX macros into
`manuscript/numbers` and the figures into `manuscript/figures`. The folder `manuscript` is created on the first run.

```
cd code
python3 make_numbers.py
python3 make_figures.py
python3 make_fig4_cir_sweep.py
python3 make_fig1_schematic.py
```

The macro files are named after their generators: `numbers.tex` (`make_numbers.py`), `numbers_isi.tex`
(`run_waveform_isi.py`), `numbers_isi_check.tex` (`check_isi_step.py`), and `numbers_mod_check.tex`
(`check_modification_bep.py`). The data figures are also written as PNG files for inspection.

`run_waveform_isi.py` and `check_isi_step.py` also accept `--macros-only`, which rewrites their LaTeX macros from the
stored results without simulating.

## Simulation conventions

- **Units.** The model is nondimensional. Concentrations are given for the system size $\Omega=1$, molecule counts are
  concentrations times $\Omega$, and one model time unit corresponds to 25 s in the physical mapping of Section V.
- **Nominal settings.** Received levels $c_0=1$ and $c_1=4$, $N_\mathrm{R}=200$ receptors, symbol duration
  $T_\mathrm{sym}=0.5$, independent and equiprobable bits, and $\Omega=200$ unless the system size is varied.
- **Stochastic simulation.** Tau-leaping with the step 0.01 (0.005 in the copy-number runs), or the exact SSA for
  $\Omega\le200$ in the copy-number runs. The ligand binding is at quasi-steady state, and the full nonlinear receptor
  map is used, except in the stability sweep, which uses a logistic sensing function of prescribed slope. Every
  trajectory has its own random symbol stream. Every run starts at the deterministic steady state of its configuration,
  except the runs of Fig. 2(a), which start from an untuned state ($y=0$).
- **Error probabilities.** The BEP is the exact binomial error probability of the fixed-threshold detector, averaged
  over the recorded modulator ensemble. The modulator is recorded at the symbol boundaries, and trajectories are the
  resampling unit of the percentile bootstrap. Error probabilities below $10^{-8}$ are reported at this threshold.
- **Tracking error.** The mean deviation of the ensemble-mean affinity from the time-varying optimum, reported as
  $100\,(e^{x}-1)$ %, where $x$ is the time average of $|\ln(\langle K_\mathrm{D}\rangle/K_\mathrm{opt})|$.
- **Seeds.** Seeds are fixed and derived from the run labels (`model.stable_seed`).

## Naming in the code

The code uses short labels, which also appear as keys in the result files.

| Code label | Name in the article |
|---|---|
| `allosteric` | non-cooperative receiver ($n_\mathrm{H}=1$) |
| `cooperative` | cooperative receiver ($n_\mathrm{H}=2.5$) |
| `coregulated` | co-regulated receiver, $n_\mathrm{H}(y)=1.5+y$ ($\tau=4$) |
| `coregulated_slow` | co-regulated receiver with a reduced actuation rate ($\tau=10$) |
| `weighted` | mixed array with the tunable fraction $w=0.6$ |
| `cooperative_a1` | cooperative receptor at the actuator gain $\alpha=1$ of the co-regulated receiver |
| `AIF` | antithetic integral feedback network |
| `CAIF` | cascaded variant with a second sequestration channel, not reported in the article |
| `static`, `static_best` | best non-adaptive receiver |
| `oracle` | genie-aided receiver |
| `stream` drive | random symbol stream sensed by the controller |
| `bitavg` drive | averaged input, i.e., the symbol-averaged occupancy without self-noise |
| `d_bits`, `with_bits` | self-noise |
| `exp`, `atcm` | exponential and bounded actuation laws |
| `surrogate` | Gaussian approximation of the BEP |
| `sf_reference` | normalized two-stage reference $S_\mathrm{f}$ |
| `waveform`, `pulsed` | CIR-based model |
| `S`, `swing` | variation depth $S$ |
| `T`, `T_c` | coherence time $T_\mathrm{c}$ |
| `gain` | BEP reduction factor |
